# 🏡 Find Your Home  

**Find Your Home** is a full-stack real estate listing platform built with the **MERN stack**.  
It helps users find homes for **ownership** or **rent** with a modern, responsive UI powered by **ShadCN**.  
Users can browse property listings, search with filters, save favorites, and manage authentication securely using **JWT**.  

## 🌟 Why Find Your Home?  

Finding the right home can be overwhelming with scattered listings and outdated platforms.  
**Find Your Home** solves this by offering:  

- 🖥️ **Modern UI/UX** for a smooth browsing experience  
- 🔎 **Smart search and filters** to quickly find homes based on needs  
- 🔐 **Secure authentication** with JWT  
- 🏘️ A **centralized platform** for both rental and ownership listings  

Whether you're buying your dream home or renting, **Find Your Home** makes it simple.  

## 🔑 Key Features  
- 🏠 **Property Listings** → Browse homes for sale or rent  
- 🔎 **Advanced Search & Filters** → Find homes by price, location, or type  
- 👤 **User Authentication** → Secure login/signup with JWT  
- ❤️ **Favorites (Wishlist)** → Save homes for later  
- 🎨 **Modern UI** → Built with **TailwindCSS + ShadCN**  
- ⚡ **Fast & Responsive** → Smooth navigation on all devices  

---

## 🛠 Tech Stack  
### Frontend  
- ⚛️ **React.js** → Component-based UI  
- 🎨 **TailwindCSS + ShadCN** → Responsive, modern styling  
- 🌐 **Axios** → API communication  
- 🧭 **React Router** → Client-side navigation  

### Backend  
- 🚀 **Node.js + Express.js** → REST API & server logic  
- 🗄️ **MongoDB + Mongoose** → Database for users & listings  
- 🔐 **JWT Authentication** → Secure login & route access  

---

## ⚙️ How It Works  
1. **User Authentication** → Login/Signup with JWT  
2. **Browse Listings** → View homes for rent or ownership  
3. **Search & Filter** → Narrow results by location, price, or type  
4. **Save Favorites** → Add listings to your wishlist  
5. **Responsive Design** → Works across devices seamlessly
